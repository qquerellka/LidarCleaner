  LidarCleaner - Инструкция по установке и запуску
═══════════════════════════════════════════════════════════

📋 ЧТО НУЖНО УСТАНОВИТЬ:

1. Docker
2. Docker Compose
3. Node.js (версия 18+) и npm

═══════════════════════════════════════════════════════════
🐧 УСТАНОВКА ДЛЯ LINUX (Ubuntu/Debian):
═══════════════════════════════════════════════════════════

# 1. Установка Docker
sudo apt-get update
sudo apt-get install -y docker.io docker-compose

# 2. Добавить текущего пользователя в группу docker
sudo usermod -aG docker $USER

# 3. Перелогиниться или выполнить:
newgrp docker

# 4. Проверить Docker
docker --version
docker-compose --version

# 5. Установка Node.js 20 (LTS)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 6. Проверить Node.js
node --version
npm --version

═══════════════════════════════════════════════════════════
🎩 УСТАНОВКА ДЛЯ ARCH LINUX:
═══════════════════════════════════════════════════════════

# 1. Установка Docker
sudo pacman -S docker docker-compose

# 2. Включить и запустить Docker
sudo systemctl enable docker
sudo systemctl start docker

# 3. Добавить пользователя в группу docker
sudo usermod -aG docker $USER

# 4. Перелогиниться

# 5. Установка Node.js
sudo pacman -S nodejs npm

# 6. Проверить версии
docker --version
docker-compose --version
node --version

═══════════════════════════════════════════════════════════
🚀 ЗАПУСК ПРИЛОЖЕНИЯ:
═══════════════════════════════════════════════════════════

1. Перейти в директорию проекта:
   cd /path/to/LidarCleaner

2. Дать права на выполнение скрипту:
   chmod +x start-lidarcleaner.sh

3. Запустить приложение:
   ./start-lidarcleaner.sh

4. Выбрать режим:
   1 - Development (для разработки)
   2 - Production (для использования)

═══════════════════════════════════════════════════════════
✅ ПРОВЕРКА ГОТОВНОСТИ:
═══════════════════════════════════════════════════════════

Выполните эти команды, чтобы убедиться что всё установлено:

1. docker --version
   ✓ Ожидается: Docker version 20.x.x или выше

2. docker-compose --version
   ✓ Ожидается: docker-compose version 1.29.x или выше

3. node --version
   ✓ Ожидается: v18.x.x или v20.x.x

4. npm --version
   ✓ Ожидается: 8.x.x или выше

5. docker info
   ✓ Должно показать информацию о Docker (без ошибок)

🐛 ЧАСТЫЕ ПРОБЛЕМЫ:
═══════════════════════════════════════════════════════════

ПРОБЛЕМА: "Docker not found"
РЕШЕНИЕ: Установите Docker (см. выше)

ПРОБЛЕМА: "Docker daemon is not running"
РЕШЕНИЕ: 
  sudo systemctl start docker
  # Или для включения автозапуска:
  sudo systemctl enable docker

ПРОБЛЕМА: "permission denied" при запуске docker
РЕШЕНИЕ: 
  sudo usermod -aG docker $USER
  # Затем перелогиньтесь или выполните:
  newgrp docker

ПРОБЛЕМА: "npm: command not found"
РЕШЕНИЕ: Установите Node.js (см. выше)

ПРОБЛЕМА: Порт 8000 или 5173 занят
РЕШЕНИЕ: 
  # Найти процесс:
  sudo lsof -i :8000
  sudo lsof -i :5173
  # Остановить процесс:
  sudo kill -9 <PID>

📊 СИСТЕМНЫЕ ТРЕБОВАНИЯ:
═══════════════════════════════════════════════════════════

Минимальные:
  - CPU: 2 ядра
  - RAM: 4 GB
  - Disk: 10 GB свободного места
  - OS: Linux (Ubuntu 20.04+, Arch Linux)

Рекомендуемые:
  - CPU: 4 ядра
  - RAM: 8 GB

═══════════════════════════════════════════════════════════
💡 ПОЛЕЗНЫЕ КОМАНДЫ:
═══════════════════════════════════════════════════════════

# Посмотреть логи бэкенда
cd backend && docker-compose logs -f

# Пересобрать бэкенд
cd backend && docker-compose up --build -d

# Очистить всё (осторожно! удалит данные)
cd backend && docker-compose down -v

# Посмотреть запущенные контейнеры
docker ps

# Посмотреть все контейнеры (включая остановленные)
docker ps -a

# Освободить место (удалить неиспользуемые образы)
docker system prune -a
