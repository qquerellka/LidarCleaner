## Общие вопросы

### Что такое LidarCleaner?

LidarCleaner — это desktop-приложение для визуализации, редактирования и очистки облаков точек из LiDAR сканеров. Приложение поддерживает форматы PCD и PLY, и использует AI для автоматического удаления динамических объектов (машины, люди).

### Какие ОС поддерживаются?

- **Linux** (X11 и Wayland)
- **Windows** 10/11
- **macOS** 10.13+

### Бесплатно ли приложение?

Да, LidarCleaner распространяется под лицензией MIT и полностью бесплатен для использования, включая коммерческие цели.

### Где хранятся мои данные?

- **Файлы**: Все файлы хранятся локально на вашем компьютере
- **Backend**: Временно файлы загружаются в MinIO (S3-совместимое хранилище) для обработки
- **База данных**: Метаданные хранятся в PostgreSQL локально

Никакие данные не отправляются на внешние серверы.

## Установка и запуск

### Как установить LidarCleaner?

**Вариант 1: Единый скрипт (рекомендуется)**
```bash
git clone https://github.com/lidarcleaner/app.git
cd LidarCleaner
./start-lidarcleaner.sh
```

**Вариант 2: Скачать готовый пакет**
- Скачайте AppImage (Linux) / DMG (macOS) / EXE (Windows) из [Releases](https://github.com/lidarcleaner/app/releases)
- Запустите файл

### Что нужно установить перед запуском?

- **Docker** и **Docker Compose** (для backend)
- **Node.js** >= 18 (для frontend)
- **Git** (для клонирования репозитория)

### Как обновить приложение?

```bash
cd LidarCleaner
git pull origin main
cd frontend
npm install
npm run build
```

### Можно ли запустить без Docker?

Технически да, но не рекомендуется. Вам придется установить:
- PostgreSQL 15
- MinIO
- RabbitMQ
- Go 1.23

И настроить все вручную. Docker Compose делает это автоматически.

## Работа с файлами

### Какие форматы файлов поддерживаются?

**Импорт:**
- PCD (Point Cloud Data) — ASCII и Binary
- PLY (Polygon File Format) — ASCII и Binary

**Экспорт:**
- PLY (ASCII)
- PLY (Binary) — меньше размер
- PCD

### Какой максимальный размер файла?

- **Рекомендуемый**: < 200 MB
- **Предупреждение**: 200 MB - 2 GB
- **Максимальный**: 2 GB

Файлы > 2 GB не поддерживаются из-за ограничений памяти.

### Как открыть файл?

**Способ 1: Кнопка**
1. Нажмите "Open PCD File"
2. Выберите файл в диалоге

**Способ 2: Drag & Drop**
1. Перетащите файл .pcd или .ply в окно приложения

**Способ 3: Недавние файлы**
1. Нажмите стрелку рядом с "Open PCD File"
2. Выберите из списка недавних

**Способ 4: Горячая клавиша**
- `Ctrl+O` — открыть файл

### Файл не открывается. Что делать?

**Проверьте формат:**
```bash
head -20 your_file.pcd
```

Должно содержать заголовок:
```
VERSION .7
FIELDS x y z
...
```

**Попробуйте конвертировать:**
```bash
# PCD binary → ASCII
pcl_convert_pcd_ascii_binary input.pcd output.pcd 0
```

См. [TROUBLESHOOTING.md](TROUBLESHOOTING.md) для деталей.

### Можно ли загрузить несколько файлов одновременно?

В текущей версии (v0.1.0) — нет. Поддержка мультифайлов планируется в v0.3.0.

## Редактирование

### Как выделить точки?

**Box Selection (прямоугольник):**
1. Нажмите `B` или выберите "Box" в меню
2. Зажмите ЛКМ и тащите мышь
3. Отпустите — точки в прямоугольнике выделены

**Brush Selection (кисть):**
1. Нажмите `V` или выберите "Brush" в меню
2. Наведите на точки — preview выделения
3. Кликните ЛКМ — выделить
4. `[` / `]` — изменить размер кисти

**Модификаторы:**
- `Ctrl + клик` — добавить к выделению
- `Alt + клик` — убрать из выделения

### Как удалить точки?

1. Выделите точки (Box или Brush)
2. Нажмите `Delete` или `Backspace`

Или используйте Quick Actions Toolbar → кнопка "Delete".

### Как отменить действие?

- `Ctrl+Z` — отменить последнее действие
- `Ctrl+Shift+Z` — повторить отменённое

История хранит последние 20 действий.

### Как скрыть точки без удаления?

1. Выделите точки
2. Нажмите `H` — скрыть
3. `Alt+H` — показать все скрытые

### Как изолировать выделение?

1. Выделите точки, которые хотите оставить видимыми
2. Нажмите `I` — все остальные точки скроются

### Как выделить все точки?

`Ctrl+A` — выделить все видимые точки

### Как инвертировать выделение?

`Ctrl+I` — выбранные станут невыбранными и наоборот

### Как снять выделение?

`Escape` — снять выделение

## Производительность

### Приложение тормозит при работе с большими файлами. Что делать?

**1. Уменьшите размер точек:**
- Ползунок "Point Size" → минимум

**2. Отключите цвета:**
- "Color Mode" → "Fixed Color"

**3. Downsampling:**
```python
# Используйте внешние инструменты для уменьшения точек
import open3d as o3d
pcd = o3d.io.read_point_cloud("large.pcd")
downsampled = pcd.voxel_down_sample(voxel_size=0.05)
o3d.io.write_point_cloud("small.pcd", downsampled)
```

**4. Увеличьте RAM:**
- Docker настройки → Resources → Memory → 8GB+

### Сколько RAM нужно?

| Точек | RAM (рекомендуется) |
|-------|---------------------|
| < 1M  | 4 GB               |
| 1-5M  | 8 GB               |
| 5-10M | 16 GB              |
| > 10M | 32 GB              |

### Низкий FPS при вращении камеры

- Уменьшите размер точек
- Используйте фиксированный цвет вместо vertex colors
- Закройте другие приложения
- Обновите драйверы GPU

## AI-обработка

### Что делает "Auto Clean"?

"Auto Clean" использует алгоритмы компьютерного зрения (RANSAC, DBSCAN) для автоматического удаления динамических объектов из облака точек:
- Автомобили
- Люди
- Временные объекты

Остаются только статические объекты (здания, дороги, столбы).

### Сколько времени занимает обработка?

Зависит от размера файла:
- **< 1M точек**: 2-5 минут
- **1-5M точек**: 5-15 минут
- **> 5M точек**: 15-30 минут

### Можно ли отменить обработку?

Да, нажмите кнопку "Cancel" во время обработки.

### Можно ли настроить алгоритм?

В текущей версии — нет. Используются дефолтные параметры. Кастомизация планируется в будущих версиях.

### Backend возвращает ошибку при обработке

**Проверьте логи:**
```bash
cd backend
docker-compose logs -f app
```

**Частые причины:**
- Недостаточно памяти
- Неверный формат файла
- Backend не запущен

См. [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Экспорт и сохранение

### Как сохранить изменения?

**Экспорт в файл:**
1. Нажмите "Export" в правой панели
2. Выберите формат (PLY, PLY Binary, PCD)
3. Выберите место сохранения

**Горячие клавиши:**
- `Ctrl+S` — сохранить
- `Ctrl+Alt+S` — сохранить как

### В каком формате лучше сохранять?

- **PLY Binary** — рекомендуется (меньше размер, быстрая загрузка)
- **PLY ASCII** — если нужна читаемость
- **PCD** — для совместимости с PCL (Point Cloud Library)

### Сохраняются ли цвета точек?

Да, при экспорте в PLY цвета сохраняются.

### Можно ли сохранить историю изменений?

Нет, при экспорте сохраняется только финальное состояние облака точек.

## Troubleshooting

### Backend не отвечает

```bash
# Проверьте health
curl http://localhost:8000/health

# Перезапустите
cd backend
docker-compose restart
```

### Electron окно не открывается

```bash
# Убейте процессы
pkill -f electron
pkill -f node

# Перезапустите
npm run dev
```

### Файл загружается, но не отображается

1. Проверьте консоль DevTools (`Ctrl+Shift+I`)
2. Проверьте количество точек (должно быть > 0)
3. Попробуйте сбросить камеру (кнопка "Reset Camera")
